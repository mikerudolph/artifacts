## Built for work that outlives a context window

Artifacts separates durable publication from disposable local state. Postgres owns the refs, object storage holds immutable packs, and local bare repositories can always be reconstructed.

<div class="feature-grid">
  <div>
    <h3>Git-compatible</h3>
    <p>Clone and push with existing Git clients. Repository-scoped credentials keep each handoff contained.</p>
  </div>
  <div>
    <h3>REST-native</h3>
    <p>Create repositories, publish files, inspect refs, and read results without installing Git.</p>
  </div>
  <div>
    <h3>Snapshot-friendly</h3>
    <p>Fork metadata at a captured sequence without duplicating object bytes or following later parent changes.</p>
  </div>
  <div>
    <h3>Reconstructable</h3>
    <p>Rebuild disposable caches from snapshot lineage, checkpoints, immutable WAL packs, and authoritative refs.</p>
  </div>
</div>

## One service, two useful interfaces

Use REST when an orchestrator needs a compact control plane. Use Git when an agent or tool already speaks the protocol. Both publish into the same repository history.
