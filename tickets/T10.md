# T10 — content read API

Depends-on: T6, T8

Allowed-paths:
  - internal/api/content_log.go
  - internal/api/content_log_test.go
  - internal/api/content_commit.go
  - internal/api/content_commit_test.go
  - internal/api/content_tree.go
  - internal/api/content_tree_test.go
  - internal/api/content_blob.go
  - internal/api/content_blob_test.go
  - internal/api/content_file.go
  - internal/api/content_file_test.go
  - internal/api/content_raw.go
  - internal/api/content_raw_test.go
  - internal/api/content.go
  - internal/api/content_test.go

Forbidden-paths:
  - internal/api/server.go (see note)
  - internal/api/repos.go
  - internal/api/tokens.go
  - internal/api/namespaces.go
  - internal/api/envelope/**

Allowed-deps: none beyond T6/T8

Note: T8 must register content routes by calling `registerContent(r chi.Router)` defined in `content.go`. If T8 has not added that hook, add **only** a `registerContent` call in `server.go` — no other server.go edits.

Routes:
- GET `.../repos/{name}/log?ref=&limit=&offset=`
- GET `.../repos/{name}/commit/{hash}`
- GET `.../repos/{name}/tree/{hash}`
- GET `.../repos/{name}/blob/{hash}` → raw bytes
- GET `.../repos/{name}/file?ref=&path=` → `application/octet-stream`
- GET `.../repos/{name}/raw/{ref}/{path}` → sniffed Content-Type

Missing file → 404 / 10200.

Done:
  - tests against a repo populated via gitstore
  - `make verify`; `internal/api` ≥ 85%

Blocked-if: you need to rewrite T8 handlers
