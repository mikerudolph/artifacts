# T6 — git object storer

Depends-on: T3, T4

Allowed-paths:
  - internal/store/git/**

Forbidden-paths: everything else

Allowed-deps:
  - github.com/go-git/go-git/v5

Public API:

```go
package gitstore

func Open(objects object.Store, refs meta.Refs, account types.AccountID, repo types.RepoID) (storer.Storer, error)
```

Rules:
- Implement go-git `storer.Storer` over `object.Store` + `meta.Refs`.
- Loose objects via `object.LooseObjectKey`. Packs via `PackKey` / `PackIndexKey`.
- Ref updates go through `Refs.CompareAndSwap`.
- Do not shell out to `git`.
- Tests: write/read blob, tree, commit; update a ref with CAS; pack round-trip if you store packs.

Done:
  - `make verify`; package ≥ 85%

Blocked-if: you need to change `object.Store` or `meta.Refs`
