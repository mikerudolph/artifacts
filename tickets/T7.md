# T7 — control-plane services

Depends-on: T2, T4

Allowed-paths:
  - internal/service/**

Forbidden-paths: everything else

Allowed-deps: none beyond what T2/T4 already added

Public API:

```go
package service

type Services struct { /* ns, repos, tokens */ }

func New(meta meta.Store, now func() time.Time, publicURL string) *Services

func (s *Services) CreateNamespace(...)
func (s *Services) GetNamespace(...)
func (s *Services) ListNamespaces(...)
func (s *Services) CreateRepo(...)  // implicit namespace create; returns types.CreateRepoResult with token + remote
func (s *Services) GetRepo(...)
func (s *Services) ListRepos(...)
func (s *Services) DeleteRepo(...)  // sets status deleting; actual object cleanup is T11
func (s *Services) CreateToken(...)
func (s *Services) ListTokens(...)
func (s *Services) RevokeToken(...)
func RemoteURL(publicURL string, ns types.NamespaceName, repo types.RepoName) string
```

Rules:
- Remote is `{publicURL}/git/{ns}/{repo}.git`.
- CreateRepo mints a write token via `auth.MintRepo`.
- Names use `types.Parse*`. TTL uses `types.ParseTTL`.
- Map uniqueness to `meta.ErrAlreadyExists`.
- Do not implement fork/import (T11).

Done:
  - tests with a fake `meta.Store` in this package (or postgres via testkit if T5+T4 exist)
  - implicit namespace, unique repo, token mint/revoke, remote URL
  - `make verify`; package ≥ 85%
