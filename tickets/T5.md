# T5 — testkit

Depends-on: F0

Allowed-paths:
  - internal/testkit/**

Forbidden-paths: everything else

Allowed-deps:
  - github.com/testcontainers/testcontainers-go
  - github.com/testcontainers/testcontainers-go/modules/postgres
  - github.com/testcontainers/testcontainers-go/modules/minio

Public API:

```go
package testkit

func Postgres(tb testing.TB) (dsn string)
func MinIO(tb testing.TB) (endpoint, accessKey, secretKey, bucket string)
func GitAvailable(tb testing.TB)
func RunGit(tb testing.TB, dir string, args ...string) string
func TempRepo(tb testing.TB) (dir string)
```

Rules:
- Skip (do not fail) when Docker is unavailable.
- `GitAvailable` skips when `git` is not on PATH.
- `RunGit` fails the test on non-zero exit and returns combined output.
- `TempRepo` runs `git init -b main` and sets `user.name` / `user.email`.
- No production code.

Done:
  - tests that exercise skip-or-run paths without requiring Docker in unit CI if you can stub; if Docker is present, start postgres and minio and ping them
  - `make verify`; package ≥ 85%

Blocked-if: you need production packages
