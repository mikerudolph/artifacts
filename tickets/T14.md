# T14 — core verification skill

Depends-on: T13

Allowed-paths:
  - tickets/T14.md
  - .agents/skills/verify-artifacts/**
  - examples/agent-harness/**

Forbidden-paths: everything else

Allowed-deps: none new

Public interface:

```text
go run ./examples/agent-harness doctor
go run ./examples/agent-harness verify-core --evidence DIR
```

Configuration remains environment-based:

```text
ARTIFACTS_URL
ARTIFACTS_ACCOUNT
ARTIFACTS_API_TOKEN
```

Rules:
- Create a repository-local `verify-artifacts` skill with launch, doctor, drive, evidence, and cleanup guidance.
- Keep secrets in environment variables. Never put control or repository credentials in reports or Git command arguments.
- `doctor` is read-only and distinguishes unreachable targets, authentication failures, unexpected response shapes, and healthy instances.
- `verify-core` uses unique names and proves REST create/commit/read, real Git clone/push, REST readback, refs/WAL visibility, and deletion.
- Cleanup runs after success and failure, removes only client-side scratch state and the unique repository, and never removes evidence.
- Write `report.json` and `report.md` with redacted configuration, step outcomes, assertions, artifact digests, and failure classification.
- Seed feature references for repository lifecycle, REST/Git interoperability, and credentials.
- Do not add a production readiness endpoint, runtime controller, or new production interface.

Tests:
- Table-driven tests for redaction and failure classification.
- Doctor tests for healthy, unauthorized, malformed, and unreachable targets.
- A core-drive failure test proves cleanup from final server state rather than mock call counts.
- An integration test uses Postgres plus real Git through existing `internal/testkit` and confirms evidence survives cleanup.

Done:
- The skill passes `quick_validate.py`.
- Its instructions are exercised end to end against an isolated local instance.
- `make verify` is green; changed Go package coverage is at least 85%.

Blocked-if: a new dependency, exported production interface, or edit outside Allowed-paths is required
