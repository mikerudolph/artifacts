# T2 — tokens

Depends-on: F0

Allowed-paths:
  - internal/auth/**

Forbidden-paths: everything else

Allowed-deps: none (stdlib only; use `crypto/sha256`, `crypto/rand`, `crypto/subtle`)

Public API:

```go
package auth

// Repo token format: art_v1_<40 hex>?expires=<unix_seconds>
func MintRepo(scope types.Scope, ttl time.Duration, now time.Time) (plaintext string, hash string, id types.TokenID, expires time.Time, err error)
func ParseRepo(plaintext string) (secret string, expires time.Time, err error)
func HashRepo(secret string) string
func VerifyRepo(plaintext, storedHash string, now time.Time) error

// Control-plane API token
func HashAPI(plaintext string) string
func VerifyAPI(plaintext, storedHash string) error
```

Rules:
- Secret is 40 lowercase hex chars. ID is the first 16 hex chars of the secret (CF-shaped).
- Hash is hex(sha256(secret)); never store plaintext.
- `ParseRepo` must accept the full `art_v1_…?expires=…` string and the secret-only form.
- Expired tokens (`expires <= now`) return a distinct exported error `ErrExpired`.
- Malformed tokens return `ErrInvalidToken`.
- Hash compare is constant-time.
