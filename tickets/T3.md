# T3 — object store backends

Depends-on: F0

Allowed-paths:
  - internal/store/object/fs/**
  - internal/store/object/s3/**

Forbidden-paths:
  - internal/store/object/*.go (do not change the frozen interface or keys)
  - internal/store/object/objecttest/**

Allowed-deps:
  - github.com/aws/aws-sdk-go-v2
  - github.com/aws/aws-sdk-go-v2/config
  - github.com/aws/aws-sdk-go-v2/credentials
  - github.com/aws/aws-sdk-go-v2/service/s3

Public API:

```go
package fs
func New(root string) (object.Store, error)

package s3
func New(ctx context.Context, cfg config.S3) (object.Store, error)
```

Rules:
- Implement `object.Store` only. Do not change method set.
- Both backends must pass `objecttest.Run`.
- Keys are as produced by `object.LooseObjectKey` / `PackKey` (relative).
- S3 must honor `Endpoint`, `UsePathStyle`, `Prefix`, region, static keys.
- `Delete` of a missing key succeeds.
- `Get` of a missing key returns `object.ErrNotFound`.
- Unit tests for fs use `t.TempDir()`.
- S3 tests: if `S3_BUCKET` is unset, skip; otherwise run `objecttest.Run` against the configured bucket (prefix with a unique test id).

Done:
  - `objecttest.Run` green for fs (always) and s3 (when env present)
  - `make verify`; both new packages ≥ 85%

Blocked-if: you need to change `object.Store` or key layout
