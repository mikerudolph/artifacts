# T9 — git smart HTTP

Depends-on: T2, T6

Allowed-paths:
  - internal/githttp/**

Forbidden-paths: everything else

Allowed-deps:
  - github.com/go-git/go-git/v5
  - github.com/go-chi/chi/v5

Public API:

```go
package githttp
func New(open func(ns, repo string) (storer.Storer, error), tokens TokenLookup) http.Handler

type TokenLookup interface {
    Lookup(ctx context.Context, ns, repo, plaintext string) (types.Scope, error)
}
```

Routes:
- `GET /git/{ns}/{repo}.git/info/refs?service=git-upload-pack|git-receive-pack`
- `POST /git/{ns}/{repo}.git/git-upload-pack`
- `POST /git/{ns}/{repo}.git/git-receive-pack`

Rules:
- Accept `Authorization: Bearer art_v1_…` and HTTP Basic (password = token secret or full token).
- read scope: clone/fetch only. write scope: push.
- Protocol: upload-pack v1 and v2 if go-git supports it; receive-pack v1 only.
- Integration tests with real `git` via `testkit` (skip if no git): init, commit, push, clone, fetch.

Done:
  - real git CLI tests
  - unauthorized / read-token-on-push rejected
  - `make verify`; package ≥ 85%

Blocked-if: you need to change `gitstore` or `auth`
