Routes (relative to `/client/v4/accounts/{account_id}/artifacts`):
- POST/GET `/namespaces`
- GET `/namespaces/{namespace}`
- POST/GET `/namespaces/{namespace}/repos`
- GET/DELETE `/namespaces/{namespace}/repos/{name}`
- GET `/namespaces/{namespace}/repos/{name}/tokens`
- POST `/namespaces/{namespace}/tokens`
- DELETE `/namespaces/{namespace}/tokens/{id}`

Rules:
- Bearer `Authorization` required unless `cfg.Auth.Mode == none`.
- DELETE repo returns 202 + `{id}`.
- List repos: `limit`, `cursor`, `search`, `sort`, `direction`.
- List tokens: `state`, `per_page`, `page`.
- Use `envelope` for all JSON. Do not add content routes (T10).
