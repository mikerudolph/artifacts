Rules:
- Implement every `meta` interface. Do not change them.
- Unique `(account_id, namespace.name)` and `(namespace_id, repo.name)`.
- `Refs.CompareAndSwap`: empty oldSHA means the ref must not exist; empty newSHA deletes; mismatch returns `meta.ErrCASConflict`.
- `RunInTx` must pass a Store bound to the same transaction.
- Repo `status` stored as `types.RepoStatus`.
- IDs: `repo_` + 16 hex for repos; 16 hex for tokens/jobs; ulid/hex for namespaces. Keep them opaque strings.
- Tests use `DATABASE_URL` or skip. Prefer `internal/testkit` if T5 has already landed; otherwise raw pgx + skip.
