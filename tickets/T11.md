# T11 — fork, import, delete jobs

Depends-on: T6, T7

Allowed-paths:
  - internal/jobs/**
  - internal/service/fork.go
  - internal/service/fork_test.go
  - internal/service/import.go
  - internal/service/import_test.go

Forbidden-paths:
  - internal/service/*.go other than fork.go / import.go (and their tests)

Allowed-deps:
  - github.com/go-git/go-git/v5

Public API:

```go
package jobs
func New(meta meta.Store, objects object.Store, publicURL string) *Runner
func (r *Runner) Fork(ctx, account, srcNS, srcRepo, dst types.ForkRepoInput) (types.CreateRepoResult, error)
func (r *Runner) Import(ctx, account, ns, name types.RepoName, in types.ImportRepoInput) (types.CreateRepoResult, error)
func (r *Runner) Delete(ctx, account, ns, name) error
```

Rules:
- Set repo status `forking` / `importing` / `deleting`. Other callers see `meta` + you should return a domain error that T1/T8 maps to 10303 / 10302.
- Fork: copy objects (`Store.Copy` / list prefix) and refs. `DefaultBranchOnly` copies only the default branch ref.
- Import: fetch public HTTPS (go-git). Support `branch` and `depth`. Invalid URL → wrap `types`/domain so envelope can emit 10104. Auth required remotes → 10106. Unreachable → 10401.
- Delete: 202 semantics live in T8; this job deletes objects by prefix, refs, tokens, then the repo row.
- Result includes `objects` count on fork.

T8 may not exist yet. Export service methods; T8/T12 wire them. If `internal/api` already has repos.go, you may add **only** the fork and import handler files:

  - internal/api/fork.go
  - internal/api/fork_test.go
  - internal/api/import.go
  - internal/api/import_test.go

and a `registerJobs(r)` hook. Do not edit other api files except one `registerJobs` call.
